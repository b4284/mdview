# Tabs

Tab choices are linked: pick one and every group with the same id follows.

## Install

# [Windows](#tab/windows)

```powershell
winget install example
```

# [Linux](#tab/linux)

```sh
sudo apt install example
```

## Run

#### [Windows](#tab/windows)

Run `example.exe`.

#### [Linux](#tab/linux)

Run `./example`.
